# 桌宠 · 精简版（9 大能力）

透明桌面宠物 Electron 应用，含 9 大能力：

1. **待办** — 增删 / 打勾 / 每日重置（AI 未开也可用）
2. **设置** — AI 开关、API Key、人设、长期记忆
3. **对话** — 与角色聊天（需 API Key）
4. **看屏幕** — 截图 + 视觉模型以角色口吻回应（需 API Key）
5. **戳一戳 ×3** — 左键连点 3 下触发弹动 + 气泡
6. **拖到边缘变换** — 按住拖动移动；贴屏幕边缘自动缩进
7. **主动话题** — 每隔数分钟概率性主动说话（需 API Key）
8. **长期记忆** — 设置里记 / 导出 / 导入，可自动从对话学习
9. **🍅 番茄钟** — 25 分钟专注 + 5 分钟休息循环，纯本地计时，支持开始/暂停/重置/跳过/自定义时长，到点系统通知 + 气泡提醒 + 今日/累计统计

## 无图预览（零依赖，推荐先看这个）

直接用浏览器打开 `index.html` 即可预览全部功能（角色用 CSS 占位脸，数据存在浏览器 localStorage）。
番茄钟、待办、设置、戳一戳、对话（离线提示）都可直接交互。

## 运行真实桌宠（透明窗）

```bash
npm install
npm start
```

把你的角色图命名为 `char-daily.png` 放进 `assets/` 目录（无图时自动显示 CSS 占位脸）。
AI 功能：在「设置」里填 API Key（支持智谱 / 火山引擎等 OpenAI 兼容服务）并开启 AI 开关。

## 打包 EXE（可编辑）

```bash
npm install electron-builder --save-dev
# package.json 加 "build": { "asar": false }
npm run dist
```

装好的 `resources/app/` 为明文，可直接改。
